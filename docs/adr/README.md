# Architecture Decision Records (ADR) — RestroGest
 
Este directorio documenta las decisiones de arquitectura significativas tomadas durante el desarrollo de RestroGest: qué se decidió, qué alternativas se consideraron y por qué se descartaron, y qué consecuencias trae la decisión.
 
Formato usado (Michael Nygard): **Contexto → Decisión → Alternativas consideradas → Consecuencias**. Cada ADR es inmutable una vez aceptado — si una decisión cambia, se crea un ADR nuevo que reemplaza al anterior y se referencian mutuamente, en vez de editar el original.
