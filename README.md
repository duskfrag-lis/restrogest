# RestroGest

Plataforma de gestión de restaurante - monorepo fullstack.

## Stack 
- **Frontend:** React + TypeScript + Vite
- **Backend:** Node.js + Express + TypeScript
- **Base de datos:** PostgreSQL
- **Pasarela de pago:** Wompi
